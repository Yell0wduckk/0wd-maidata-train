# 推理回溯预算恢复

2026-10-14。修复仅影响推理搜索，不改训练、checkpoint、缓存语义或 Physical 定义。

原实现预算耗尽时关闭 Physical hard-mask，但丢弃所有较早搜索帧，并继续使用已耗尽预算。若当前未完成 Hold/Slide 在音频边界内没有合法时长，重试立即失败，无法撤销该部分。

现在保留最近完整前缀的一个恢复检查点，即使长链已把其搜索帧挤出普通回溯队列。先按原策略绕过 Physical 重试；仍无候选时恢复完整前缀，撤销未完成音符、对应 KV/规则/重复历史及流式活动片段，再通过模型原 MOMENT 头和时间支持树向后推进，下一起音必须晚于失败位置，防止贪心采样反复回到同一点。基础语法、音频边界、温度/top-k/top-p规则不放宽，不伪造 duration 或窗口终端。若该完整前缀也没有合法时间候选，仍报告真实无法完成错误，避免重复重试同一前缀。

报告继续提供 `physical_fallback` 和 `physical_bypass`；前者新增 `recoveries`，记录恢复 token 位置、丢弃的未完成 token 数及下一起音的最小 tick。每窗恢复请求的 hard-mask 策略。详细 trace 仍默认关闭。

回归覆盖 Hold、长于回溯队列的链式 Slide、默认/已关闭 Physical、完整前缀保留、流式回滚、基础错误不能绕过及下一窗口策略恢复。Windows CPU 的兼容 epoch010、8秒音频、seed8835 原失败样例修复后完成三个窗口；预解码及常驻续写/范围生成也已验证。产物见工作区 `artifacts/miacode-beta-v2-20261014/fixed`，不据此判断谱面质量。
