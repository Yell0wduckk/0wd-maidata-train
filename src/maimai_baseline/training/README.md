# 训练实现

来源训练的 runner、数据装配、更新、保存与恢复，包括音频草稿和显式 A、B、SFT 等入口。通用入口按请求派发阶段；数据、缓存及后续阶段由相应流程显式组织。

来源的一拍草稿路线为外部冻结音频特征、非 AR 草稿及下游 A，未启用 MajRadar/GMM prior 或 B。其他保留入口各有适配限制，存在入口并不表示可以直接用于任意配方。

新联合音频 encoder 的训练流程尚未实现。本副本未附带训练数据、checkpoint 或外部教师；来源启动脚本也不构成本工作区的默认执行流程。

仓库定位见 [README](../../../README.md)，当前范围见 [current-runtime](../../../docs/current-runtime.md)。
