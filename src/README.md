# Python 源码

这里是本独立仓库的 Python 包根，保留 `pyproject.toml` 使用的 `src` 布局。`maimai_baseline` 依赖同目录的 `maimai_dataset` 和 `maimai_chart_ir`；开发和导入使用本仓库源码。

本副本继承 `main-new-audio-draft-beat` 的实现。计划中的全曲/局部联合音频 encoder 尚未实现；已有模型、训练入口和配置不能视为该新架构的成品。

仓库定位见 [README](../README.md)，当前范围见 [current-runtime](../docs/current-runtime.md)。
